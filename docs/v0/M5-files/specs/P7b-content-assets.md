## 3. 局部裁定及与设计的补充

1. **复用上传协议，按用途提供小策略。** `UploadSession` 保持 prepare→原 File PUT→complete、有限恢复和取消的唯一实现；资料与内容宿主分别提供生命周期/文件校验。与复制整套状态机相比，修复只需一个落点；不把资料权限直接套给工作项。代价是 T2 须重跑全部 P6 上传及权限联合回归。
2. **没有 new_issue 范围。** 普通未保存工作项不上传；图片入口说明先创建工作项或明确“保存草稿”。保存草稿仍由用户主动操作，取得真实 Draft.id 并重新打开后启用；访客不因此被迫创建无权使用的草稿。不扩 API，不暗中 POST 草稿，代价是新建普通工作项不能同一次提交夹带图片。
3. **已有草稿可无项目。** 资产沿作者/工作区授权，`project_id=null` 合法；不能用项目成员权限额外禁止私有草稿读取/编辑。切项目或发布先终止旧视图、等待当前传输终态并保存，再调用既有草稿 API；失败保留文稿且以新视图重新授权，旧视图永久结束。项目迁移和发布不由前端逐个搬资产。
4. **编辑器只接图片。** 普通附件使用独立附件区；纯非图片文件的粘贴/拖入返回未处理，不 preventDefault。混合文件整批不接收并提示只拖图片，避免接受一半又吞掉另一半；只读/未提供图片能力时不接文件。删除旧普通附件 MIME 白名单。
5. **新评论的普通附件才进入 attachment_ids。** 图片靠正文 UUID 绑定；普通附件最多 100 个，准备完成后随单次评论 POST 提交。HTTP/网络结果未知时保留文稿与准备件、提示先核对评论列表，不自动重发。新评论仍遵守现有非空正文合同，本阶段不增加“纯附件空评论”的服务端语义。
6. **编辑器撤销/删除节点只改文稿。** 已绑定描述图片不能 DELETE；Undo/Redo、历史恢复不调用 restore、不复制同一个已完成节点，不复活私有准备件权限。取消/卸载不自动DELETE；草稿未完成件仍可能阻止发布，需沿P7a查询显示当前作者的未绑定准备件，由用户逐项明确丢弃后再发布，不能只等七天GC冒称即时恢复。其他未绑定件保留原期限回收；普通附件删除与准备件丢弃复用原DELETE，不删已绑定历史图。
7. **下载用已有内容能力。** 内容端点没有 `download` 查询参数；普通附件由既有 Content-Disposition 下载。为图片工具栏及跨源统一提供可靠文件名，用户主动下载时有限、可取消地读取原始字节到 Blob，再生成临时下载链接；不新增后端参数或把过期 URL 当永久链接。内存上限受真实资产大小与实例最大 100 MiB 限制，读超长即取消；详见子合同。
8. **包的 optional 图片能力是显式不支持。** 删除必填旧 TFileHandler 及返回空串的假回调。M6/M7/M8 未接通页面不提供能力、不发文件请求，保留其原有领域边界；不能为了删旧包顺便恢复它们的 API。旧 copyMarkdownToClipboard 不新增消费者，继续受控 getMarkDown/useCopyText；具名风险保留到 P8。

9. **恢复与副本最终结果。** 草稿上传申请回包丢失、失败duplicate、重新选文件均可从P7a查询恢复；不能把“本地已取消”当“服务端无pending”。普通工作项副本最终返回Issue，草稿副本最终返回Draft；含图时只在用户明确提交后建一次真实目标draft，逐图复制/保存，普通副本再publish，只有确认最终实体才成功关闭。部分失败/取消保留同一目标和已完成映射，给回到保留草稿的路径；未知创建/发布先核验，不自动重建。详见编辑器子合同§4。

以上除负责人已批准P7a恢复协议外，是既有 M5 设计范围内的局部落地，不改变服务器授权、事务、表、能力 TTL 或 M4/M3 的唯一权限事实来源。实施发现必须修改这些合同的新问题时，按纪律先提交再上报。

## 6. 风险与退路

- 旧节点接口与新协议差异较大：T7 先应用小端口和测试，T8 同 Task 迁移全部包内及 wrapper 调用形状，不能让产品检查点依赖空桩或不通过类型的中间态。
- 资源授权来自服务器与现有 owner store；可见项目不代表工作项可见。首读先取得当前宿主正文/评论/草稿，附件 GET/content GET 仍逐次后端授权；本地仅限制失效与入口，不宣称可撤销已签 S3 URL。
- 文件下载占用最多 100 MiB 加 Blob 的浏览器内存；采用流式上限与单次在途，销毁后 revoke。容量演练归 P8，P7 必须实际验证取消、超长与失败释放。
- 被移除的草稿/评论可能仍有迟到资产回答；本阶段资源视图与节点各有单调生命期，宿主切换/已观察删除后即结束；不能只比较当前 ID 相等来通过 A→B→A。
- 未知非幂等复制/评论创建结果不能自动重试；普通内容孤立私有副本由现有清理承担，草稿另提供P7a查询与明确丢弃，不能让未知ID阻塞即时恢复发布。UI保留明确核验路径。
