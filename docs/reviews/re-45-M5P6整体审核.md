### Local Fix — P2 / Major：创建成功但回包丢失时，提示错误地引导直接重试

位置：`web/apps/web/core/components/projects/create/use-create-project.ts:61–62`。

**触发与实际行为：** 用户选择并完成自定义封面上传，填写项目资料后提交；服务器可能已经创建项目并绑定封面，但 POST 响应因网络中断没有到达页面。`failed` 分支仍调用通用 `showRefusal`。非 Problem 的网络错误落到 `errors.unknown`，中文显示“出错了，请重试。”，英文显示“Something went wrong. Please try again.”。页面没有说明项目可能已经创建，也没有要求先核验项目列表再决定是否重试。

**修复范围：** 在创建流程内呈现可持续阅读、可被读屏发现的结果不确定说明：请求结果未能确认，项目可能已经创建，请先核验项目列表，确认未创建后再手动重试。保留字段、已完成封面的预览及资产 ID；不重传、不自动补发 POST、不自动推进成功步骤。继续沿既有错误分类处理确定的字段/权限拒绝；发送前凭据不可用、会话退休等已知未发送或已失效情形不能一概说成服务端结果未知。无需改后端协议、共享权限接口或通用拒绝语义。这是创建页面遗漏一种已有错误类别的呈现，根因不在上传状态机或资产绑定模型。
