- **拒绝次序（R2）**：先验 422 → 404 → 403（角色、OwnOnly）→ `project.archived` → `modules_disabled` → `planning.archived`（含空改动）→ 锁下 422（合并日期与资格一次报齐）→ 存储 409（名字、地址）；`TestCreateModuleRefusals`、`TestUpdateModuleRefusals`、`TestModuleLinkRefusals` 在更后的条件同时成立时钉住每一步。
- **归档、日期与资格（R3–R5）**：归档先判“已是目标状态 200 不写”再判是否已关闭，都在读时钟之前；`Apply` 与 `Newcomers` 对新负责人的判定一致，留下的成员与未改的负责人既不读角色也不检查（组合测试让一名成员离开项目后仍留在模块里）。
