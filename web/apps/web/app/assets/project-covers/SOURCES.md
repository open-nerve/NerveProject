本目录 29 个 SVG 均为本项目自制矢量绘图，使用曲线、圆弧、斜面与圆拱组成抽象图案；不含第三方图片、照片、标志或远端素材。源码即原件，不依赖外部字体、链接、滤镜或图片请求。各图为 1600 × 900，主要图形跨越画面中段，供项目卡片和设置页的宽幅裁剪。颜色保持中暗调，覆盖文字仍由页面提供足够对比。

稳定编号 cover-01…cover-29 是 API 持久值；helpers/project-covers.ts 的打包 URL 仅作显示。编号与图形的对应关系不随机变化；“随机”只响应用户点击并选取一个现存编号。未知编号显示占位。
