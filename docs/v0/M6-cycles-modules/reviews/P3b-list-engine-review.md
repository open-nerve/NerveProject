## 3. 局部裁定

台账中约 80 条 `Ruling:`，均为局部取舍，没有架构待决项，也没有需要负责人决定的问题。要点：

- **词汇的范围**：筛选与分组只限项目列表（“我的工作项”回答 422），四个排序词两种列表都可用。“我的工作项”的名字目录覆盖调用者的全部可见项目，同状态、标签、负责人。
- **目录**：`PlanningDirectory` 只在按名字排序时、在读行的同一快照里取；与 `IssueTargets` 分开交出，因为两者的锁与事实不同。
- **共用夹具**：两个场景按 spec R7 写成。Go 的两个消费者另给每行一条已删除的归属，名为 “0 left”，它不应计入。
- **网页的空目录**：生产目录给两个空 `Map`，加上大声失败的检查（R9）；网页的词表在 P7 之前收不到这些词。`issueFieldForGroup` 拆出可测的 `groupedIssueField`，行为不变。
- **共用显示设置**：显示设置的形状三页共用，契约在 `common.yaml`、Go 值在 `internal/shared`，行为不变（T6 先核实 bodyshape 能解析外部引用）。`Validate` 去掉显示属性参数，键由共用类型保证；issue 测试里两条属性键的断言随之删去，经 HTTP 时 bodyshape 本就先回答 400。
- **项目偏好**：`domain.Filters.Map()` 覆盖共用的 `Map()`，加上两个键。
- **偏好表**：两张表的 Go 守卫在建表的 Task 内转绿；删迭代/模块时在原事务软删偏好行。
- **偏好的用例**：
  - 用泛型的核心加具名的薄用例，两页不重复；
  - PATCH 走新的共享锁之路，不进写闸门，不拒绝 OwnOnly、已归档的项目/迭代/模块与开关关闭；
  - `write` 改为嵌入 `named`，行为不变。
- **网页客户端**：T12 发现 `@nerve/api-client` 的 `csvKeys` 漏了 `cycle_id`/`module_id`（T2 留下）：`none,<id>` 被发成重复参数，服务端回答 422。修正后，T13 加了对照 OpenAPI `explode` 的守卫测试，并在 `turbo.json` 让契约改动会重跑它。
- **网页守卫的依赖**：守卫测试从 `openapi-typescript/dist/lib/redoc.mjs` 导入 YAML 读取器（版本钉在 7.13.0），这正是 `gen` 脚本用的读取器。升级该依赖时，如果文件移动，这个导入会大声失败（re-61 m2）。
- 其余见台账。
